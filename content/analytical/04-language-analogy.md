# วิชา 1 · เชิงภาษา — อุปมาอุปไมยเชิงภาษา

## เป้าหมายการเรียนรู้และแนวโน้ม

- ระบุความสัมพันธ์ระหว่างคำคู่หนึ่ง แล้วหาคู่ที่มีความสัมพันธ์เดียวกัน
- แยกแยะความสัมพันธ์: คำตรงข้าม, ส่วนประกอบ, หน้าที่, ตัวอย่างของกลุ่ม, วัตถุ-วัสดุ, ผู้ทำ-สิ่งที่ทำ, เหตุ-ผล, สัญลักษณ์

**แนวโน้มที่ออกสอบ**: คำคู่กับคำคู่ "A-B : C-?" ตอบด้วยสี่ตัวเลือก — ภาษาสมัยใหม่ผสมศัพท์ราชการ

## แนวคิดหลักจากศูนย์

**อุปมาอุปไมย (analogy)** คือการเปรียบเทียบความสัมพันธ์ ไม่ใช่เปรียบเทียบคำ — ต้องหา "ความสัมพันธ์" ของคู่แรกก่อนเสมอ แล้วจึงหาคู่ที่มีความสัมพันธ์แบบเดียวกัน

**ประเภทความสัมพันธ์ที่สอบบ่อย**

| ประเภท | ตัวอย่าง |
|---|---|
| คำตรงข้าม | ดำ : ขาว |
| ส่วน-องค์ประกอบ | มือ : นิ้ว · ต้นไม้ : ใบ |
| ผู้ทำ-สิ่งที่ทำ | ชาวนา : นา · ครู : สอน |
| วัตถุ-วัสดุ | เก้าอี้ : ไม้ · เสื้อ : ผ้า |
| สิ่ง-หน้าที่ | นาฬิกา : บอกเวลา · แว่นตา : มอง |
| ตัวอย่างของกลุ่ม | กุหลาบ : ดอกไม้ · ข้าว : ธัญพืช |
| เกี่ยวข้องกัน | เข็ม : ด้าย · ปากกา : หมึก |
| เหตุ-ผล | ฝน : น้ำท่วม · แบคทีเรีย : โรค |
| สัญลักษณ์ | กกต. : เลือกตั้ง · ช้าง : ชาติ |
| คำขยายความหมาย | ไฟ : ความร้อน · น้ำ : ความชุ่มชื้น |

## กล่องหลักการ

<div class="formula-box"><div class="fb-title">📌 วิธีทำ 3 ขั้น</div>

1. **ระบุความสัมพันธ์คู่แรก** — พูดออกมาเป็นประโยค เช่น "มือ คือ ส่วนประกอบของ นิ้ว" → ความสัมพันธ์ = ส่วนของ
2. **ใช้ประโยคเดียวกันกับตัวเลือก** — "___ คือ ส่วนประกอบของ ___" ตัวเลือกไหนเข้าได้ ตอบตัวนั้น
3. **ตรวจทิศทาง** — ซ้ายไปขวา ต้องเหมือนกันทุกคู่ (A→B ไม่ใช่ B→A)
</div>

## 4 ตัวอย่าง

### ตัวอย่างที่ 1
ดำ : ขาว → ร้อน : ?
ก. ไฟ ข. หนาว ค. อุ่น ง. แดด
**วิเคราะห์**: ดำ↔ขาว = คำตรงข้าม → ร้อน ↔ หนาว **ตอบ ข**

### ตัวอย่างที่ 2
นาฬิกา : บอกเวลา → แว่นตา : ?
ก. ตา ข. มอง ค. สายตา ง. อ่านหนังสือ
**วิเคราะห์**: นาฬิกา คือเครื่องที่มีหน้าที่บอกเวลา → แว่นตา คือเครื่องที่มีหน้าที่ช่วยมอง — ชัดสุดคือ ข (มอง) **ตอบ ข**

### ตัวอย่างที่ 3
กุหลาบ : ดอกไม้ → ข้าว : ?
ก. นา ข. เกษตรกร ค. ธัญพืช ง. ข้าวโพด
**วิเคราะห์**: กุหลาบ = ชนิดหนึ่งของดอกไม้ (ตัวอย่างของกลุ่ม) → ข้าว = ชนิดหนึ่งของธัญพืช **ตอบ ค**

### ตัวอย่างที่ 4 (ยาก)
จับ : จับกุม → บอก : ?
ก. บอกเล่า ข. พูด ค. สั่ง ง. รายงาน
**วิเคราะห์**: "จับ" ขยายเป็นคำซ้อน "จับกุม" (คำคู่ความหมายเดียวกันแบบราชการ) → "บอก" ขยายเป็น "บอกเล่า" **ตอบ ก**

## กับดักที่พบบ่อย

1. มองหา "ความเกี่ยวข้องกว้าง ๆ" แทน "ความสัมพันธ์ที่แม่นยำ" — ต้องเป็นประโยคเดียวกันเด๊ะ ๆ
2. สลับทิศ — คู่แรก A→B แต่ไปเลือก B→A
3. ตัวเลือกที่ "เกี่ยวข้องแต่ความสัมพันธ์คนละแบบ" เช่น มือ:นิ้ว (ส่วนของ) vs นิ้ว:มือ (ถูกก็ใช้ได้ถ้าคู่แรกเป็นส่วนของ) — ระมัดระวังทิศ
4. คำตอบซ้ำความหมายกับคู่แรก — ไม่มีประโยชน์
