# วิชา 1 · เชิงนามธรรม — อนุกรมตัวเลข

## เป้าหมายการเรียนรู้และแนวโน้ม

- หาแบบรูปของลำดับตัวเลข แล้วทำนายตัวถัดไป / ตัวที่ n
- จดจำชนิดของอนุกรมที่ออกสอบบ่อย: เพิ่มคงที่ กำลังสอง เลขยกกำลัง ฟีโบนักชี สลับพจน์ และอนุกรมสองชั้น

**แนวโน้ม**: ข้อสอบ ก.พ. ชอบอนุกรมที่ต้องดู "ผลต่าง" หรือ "ผลต่างของผลต่าง" — และอนุกรมผสม เช่น คูณแล้วลบ

## แนวคิดหลักจากศูนย์

**อนุกรมเลขคณิต** — ผลต่างคงที่ เช่น 2, 5, 8, 11 → +3 เสมอ
**อนุกรมเรขาคณิต** — อัตราส่วนคงที่ เช่น 3, 6, 12, 24 → ×2 เสมอ
**อนุกรมกำลังสอง** — 1, 4, 9, 16, 25 → n²
**อนุกรมสองชั้น** — ผลต่างไม่คงที่ แต่ผลต่างของผลต่างคงที่ เช่น 1, 2, 4, 7, 11 → ผลต่าง +1,+2,+3,+4
**อนุกรมผสม** — คูณแล้วบวกลบคงที่ เช่น 2, 5, 11, 23 → ×2+1
**อนุกรมสลับ** — แยกเป็น 2 ชุดสลับกัน เช่น 1, 10, 2, 9, 3, 8 → ชุดคี่ 1,2,3 · ชุดคู่ 10,9,8
**อนุกรมฟีโบนักชี** — พจน์ถัดไป = ผลบวก 2 พจน์ก่อนหน้า

## กล่องหลักการ

1. **ผลต่างชั้นเดียวคงที่?** → อนุกรมเลขคณิต
2. **อัตราส่วนคงที่?** → อนุกรมเรขาคณิต
3. **ผลต่างชั้นสองคงที่?** → อนุกรมสองชั้น
4. **เพิ่มทีละกำลังสอง/กำลัง?** → เทียบกับ n², n³, 2^n
5. **พจน์คี่/คู่แยกกัน?** → อนุกรมสลับ
6. **×a±b คงที่?** → อนุกรมผสม
7. **ผลบวกสองพจน์ก่อนหน้า?** → ฟีโบนักชี

## 4 ตัวอย่าง

### ตัวอย่างที่ 1
2, 5, 8, 11, 14, ?
**วิเคราะห์**: ผลต่าง +3 ทุกพจน์ → 14+3 = **17**

### ตัวอย่างที่ 2
3, 6, 12, 24, 48, ?
**วิเคราะห์**: ×2 ทุกพจน์ → 48×2 = **96**

### ตัวอย่างที่ 3
1, 2, 4, 7, 11, ?
**วิเคราะห์**: ผลต่าง +1, +2, +3, +4 → ถัดไป +5 → 11+5 = **16**

### ตัวอย่างที่ 4 (ยาก)
2, 5, 11, 23, 47, ?
**วิเคราะห์**: ลอง ×2+1: 2×2+1=5 ✅ 5×2+1=11 ✅ 11×2+1=23 ✅ 23×2+1=47 ✅ → 47×2+1 = **95**

## เทคนิคทำเร็ว

- ลองผลต่างก่อนเสมอ — 70% ของอนุกรม ก.พ. แก้ได้ด้วยผลต่างชั้น 1 หรือ 2
- ลองคูณ/หารด้วยเลขน้อย ๆ (2, 3) ถ้าผลต่างไม่คงที่
- จดผลต่างลงบนกระดาษ: เขียนตัวเลขแต่ละพจน์และผลต่าง — เห็นแบบรูปง่ายกว่าคำนวณในใจ
- อนุกรมสลับ: ข้ามอ่านทีละพจน์ (ดึงพจน์คี่ออกมาดูแยก, แล้วพจน์คู่)
- เลขยกกำลัง 2^n: 2, 4, 8, 16, 32 — จำตาราง 2,3,4 ไว้

## กับดักที่พบบ่อย

1. หาผลต่างชั้นเดียวแล้วไม่เจอ แล้วเดาสุ่ม — ต้องลองผลต่างชั้นสอง
2. อนุกรมสลับแต่ดันหาผลต่างรวดเดียว
3. ลืมว่ามีอนุกรมประเภท "×a±b"
4. คิดเลขพลาดตอนบวกผลต่างชั้นสอง

### 📋 สรุปหน้าเดียว

- ผลต่างชั้น 1 คงที่ → +d · อัตราส่วนคงที่ → ×r
- ผลต่างชั้น 2 คงที่ → อนุกรมสองชั้น
- สลับพจน์ → แยกคี่/คู่
- ×a±b → ทดลองคูณแล้วบวกลบ
- เทียบ n² (1,4,9,16,25) และ 2^n (2,4,8,16,32)
- ฟีโบนักชี: พจน์ถัดไป = สองพจน์ก่อนหน้ารวมกัน
