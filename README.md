## ฟีเจอร์

- **เอกสารเรียน 26 บท** ครบ 3 วิชา (วิชา 1 คิดวิเคราะห์ 15 บท + วิชา 2 ภาษาอังกฤษ 6 บท + วิชา 3 ความรู้ข้าราชการ 4 บท + บทนำ) — ทุกบทมีโครงสร้าง: เป้าหมาย/แนวโน้ม → แนวคิดจากศูนย์ → กล่องสูตร → 4 ตัวอย่างแก้ทีละขั้น → กับดัก → สรุปหน้าเดียว (พิมพ์ได้) → quick check
- **ข้อสอบฝึก 230 ข้อ** (~10 ข้อต่อหัวข้อ แยกวิชา/หัวข้อ/ความยาก 3 ระดับ)
- **ข้อสอบจำลอง ชุดที่ 1 (100 ข้อ ตาม blueprint)** — เลือกชุด/ระดับการศึกษา (ต่ำกว่าปริญญาตรี/ปริญญาตรี/ปริญญาโท), จับเวลา, นำทางข้อ ติดธง, เลือกด้วยคีย์บอร์ด (1–4 / ก–ง, ←→, F ติดธง), autosave + resume อัตโนมัติ, สรุปผลรายวิชา/หัวข้อ, เฉลยละเอียดทุกข้อ กรอง "เฉพาะข้อผิด/ติดธง"
- **แฟลชการ์ดศัพท์ 156 ใบ** (หมวด office/government/business/collocation/phrasal verb/synonym/confusing words) พร้อมตัวอย่างประโยค
- **โหมดทบทวน SR** — ข้อที่เคยผิด + บุ๊กมาร์ก ทบทวนแบบ Leitner (กล่อง 0–5)
- **แดชบอร์ด** — ประวัติการสอบ กราฟแนวโน้มคะแนน (SVG) หัวข้ออ่อนที่สุด + คำแนะนำบทที่ควรอ่านซ้ำ

## โครงสร้างโปรเจกต์

```
config/exam-spec.json      แหล่งความจริงเดียวของสเปกข้อสอบ (verified: false — ดู REVIEW.md)
content/                   เนื้อหาบทเรียน Markdown (frontmatter slug/title/subject/order/exam_topics)
data/questions/            คลังข้อสอบ JSON (p-*.json = ฝึก, mock-set-N.json = ชุดจำลอง)
data/flashcards.json       แฟลชการ์ด
assets-src/                ซอร์สเว็บ (แก้ที่นี่ ห้ามแก้ dist/ ตรง ๆ)
scripts/build.py           แปลง content+data → dist/
scripts/validate_questions.py  ตรวจ schema/blueprint/id/stem ซ้ำ
scripts/check_math.py      คำนวณคำตอบข้อคณิตศาสตร์ซ้ำโดยอิสระ (sidecar: scripts/math_checks.json)
scripts/playwright_smoke.py    ทดสอบ file:// ครบวงจรผ่าน Chromium
dist/                      เว็บที่พร้อมใช้ (build ใหม่ได้เสมอ ลบทิ้งได้)
PLAN.md / PROGRESS.md / REVIEW.md   สถานะ ผลตรวจ และทะเบียนสิ่งที่ต้องตรวจ
```

## วิธี build ใหม่

```powershell
cd "กพ.-ก"
$env:PYTHONUTF8='1'
python scripts\build.py      # สร้าง dist/ ใหม่ (สรุปจำนวนหน้า/ข้อ + สแกน external URL)
python scripts\validate_questions.py
python scripts\check_math.py
python scripts\playwright_smoke.py   # ต้องมี Playwright + Chromium
```

## วิธีเพิ่มข้อสอบ

1. เพิ่มข้อใน `data/questions/p-<subject>-<NN>.json` ตาม schema ใน `prompt.md` (id ห้ามซ้ำ — validate จะเช็ค)
   - `study_ref` ต้องตรงกับ `slug:` ในไฟล์เนื้อหา
   - ข้อคำนวณต้องเพิ่ม sidecar ใน `scripts/math_checks.json` (method/params/result) เพื่อให้ check_math.py ยืนยัน
   - ข้อกฎหมาย/ข้อเท็จจริงที่ยืนยันไม่ได้ → `"needs_review": true`
2. รัน validate + check_math + build · ตรวจว่าผ่านหมดก่อนส่งต่อ
3. ชุดจำลองใหม่: สร้าง `data/questions/mock-set-2.json` (array ของข้อสอบ) — รายการจะไปโผล่ในหน้าเลือกชุดอัตโนมัติ (ชุด 2 ยังไม่สร้าง — ดู PROGRESS.md)

## วิธีเพิ่ม/แก้เนื้อหาบทเรียน

1. แก้/เพิ่มไฟล์ `content/<subject>/<NN>-<name>.md` (ดู frontmatter ของไฟล์เดิมเป็นตัวอย่าง)
2. โครงสร้างคงเดิม: `## เป้าหมายการเรียนรู้และแนวโน้ม` → `## แนวคิดหลัก` → `.formula-box` → `## 4 ตัวอย่าง` → `## กับดัก` → `.cheat-sheet` → `## Quick check`
3. สูตรเลขใช้ HTML `.frac` (ไม่ใช้ KaTeX), รูปใช้ inline `<svg>`
4. รัน build ใหม่

## ข้อจำกัดที่รับรู้ (ตรวจสอบเองก่อนใช้)

- สเปกข้อสอบ (จำนวนข้อ/คะแนน/เกณฑ์ผ่าน/เวลาสอบ/blueprint) — เป็นค่าตั้งต้น ยังไม่ยืนยัน (needs_review)
- เวลาสอบจริงไม่ทราบ (หน้า Settings ให้ตั้งเอง ค่าแนะนำ 180 นาที "ไม่ใช่ค่าทางการ")
- จำนวนข้อวิชา 2: 25 ข้อ (บางแหล่งว่า 20) — ค่าตั้งต้น
- เกณฑ์ผ่านคิดรวมหรือรายวิชา — ตั้งเป็นรายวิชา (per_subject) ยังไม่ยืนยัน
- เลขมาตรากฎหมายทุกจุดในวิชา 3 และข้อสอบวิชา 3 — ยืนยันจากแหล่งทางการไม่ได้ ติดป้าย "รอตรวจสอบมาตรา" และ needs_review
- ข้อสอบทั้งหมดเขียนใหม่เอง (ไม่คัดลอกข้อสอบจริง) ในแนวข้อสอบ ก.พ. — คุณภาพดีที่สุดที่ตรวจสอบได้ แต่ไม่ได้รับประกันจากสำนักงาน ก.พ.
