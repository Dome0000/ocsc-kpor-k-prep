# วิชา 1 · เชิงภาษา — เงื่อนไขภาษา (ตรรกะจากถ้อยความ)

## เป้าหมายการเรียนรู้และแนวโน้ม

- อ่านถ้อยความเชิงเงื่อนไข "ถ้า…แล้ว…" แล้วสรุปผลที่ถูกต้อง
- จับผิดข้อความที่สมมูล/ผกผัน (contrapositive)
- แยก "จำเป็น vs เพียงพอ"

**แนวโน้มที่ออกสอบ**: ข้อความ 2–4 เงื่อนไข แล้วถาม "ข้อใดสรุปได้" / "ข้อใดไม่เป็นไปตามเงื่อนไข" — ใกล้เคียงตรรกศาสตร์แต่ใช้ภาษาไทย

## แนวคิดหลักจากศูนย์

**เงื่อนไขเพียงพอ (ถ้า P แล้ว Q)** — เขียน P → Q
- ถ้า P จริง → Q จริงเสมอ
- Q จริง ไม่ได้แปลว่า P จริง (อาจมีสาเหตุอื่น)
- ถ้า Q เท็จ → P ต้องเท็จ (contrapositive)

**เงื่อนไขจำเป็น (ต้องมี P จึง Q)** — เขียน Q → P (กลับทิศ!)
- "คนไทยทุกคนต้องเคารพกฎหมาย" = เคารพกฎหมาย ← เป็นคนไทย → คนไทย → เคารพกฎหมาย

**ภาษาที่ใช้ในข้อสอบ**
| สำนวน | ความหมายเชิงตรรกะ |
|---|---|
| "ถ้า…แล้ว…" / "หาก…ก็…" | P → Q |
| "ก็ต่อเมื่อ" | P ↔ Q (ทั้งไปและกลับ) |
| "ต้อง…จึง…" / "จําเป็นต้อง" | เงื่อนไขจำเป็น Q → P |
| "ทุกคนที่…ต้อง…" | ∀: เป็น P → ต้อง Q |
| "บางคน" | ∃: มีอย่างน้อย 1 |
| "ไม่มี" / "ห้าม" | ∀ ไม่: ไม่มี P ที่ Q |

## กล่องหลักการ

<div class="formula-box"><div class="fb-title">📌 ตารางค่าความจริงของ P → Q</div>

| P | Q | P → Q |
|---|---|-------|
| จริง | จริง | จริง |
| จริง | เท็จ | **เท็จ** (ห้ามเกิด!) |
| เท็จ | จริง | จริง (P เท็จ ไม่ผูกพัน) |
| เท็จ | เท็จ | จริง |

**เทคนิค 3 ข้อ**
1. ทวน P → Q ด้วย contrapositive: "ไม่ Q → ไม่ P" (สมมูลเสมอ)
2. อย่าสลับ: Q → P ไม่สมมูลกับ P → Q
3. "ไม่ P → ไม่ Q" ก็ไม่สมมูลเช่นกัน (เพียงแต่เป็น inverse ที่ไม่สมมูล)
</div>

## 4 ตัวอย่าง

### ตัวอย่างที่ 1
เงื่อนไข: "ถ้าฝนตก ถนนจะเปียก" — ข้อใดสรุปได้?
ก. ถนนเปียก แสดงว่าฝนตก ข. ถ้าถนนไม่เปียก แสดงว่าฝนไม่ตก ค. ฝนไม่ตก ถนนไม่เปียก ง. ถนนเปียกทุกครั้งต้องมีฝน
**วิเคราะห์**: P→Q, contrapositive = ¬Q→¬P: ไม่เปียก → ไม่ตก ✅ **ตอบ ข** (ก สลับทิศ ค สลับและ negate ผิด ง overreach)

### ตัวอย่างที่ 2
"ข้าราชการทุกคนต้องซื่อสัตย์" — ข้อใดถูก?
ก. ถ้าซื่อสัตย์ แสดงว่าเป็นข้าราชการ ข. ถ้าไม่ซื่อสัตย์ แสดงว่าไม่ใช่ข้าราชการ ค. คนซื่อสัตย์ทุกคนเป็นข้าราชการ ง. ไม่มีคนซื่อสัตย์เป็นข้าราชการ
**วิเคราะห์**: เป็นข้าราชการ → ต้องซื่อสัตย์ (P→Q) contrapositive: ไม่ซื่อสัตย์ → ไม่ใช่ข้าราชการ ✅ **ตอบ ข**

### ตัวอย่างที่ 3
"หากโครงการได้รับอนุมัติจากคณะรัฐมนตรี จึงจะเริ่มดำเนินการได้"
ก. อนุมัติ → เริ่มได้ ข. เริ่มได้ → อนุมัติแล้ว ค. ถูกทั้ง ก และ ข? หรือ…
**วิเคราะห์**: "หาก…จึงจะ…" = เงื่อนไขจำเป็น: เริ่มได้ → อนุมัติแล้ว (ข ถูก) ส่วน ก เป็นเพียงพอ ซึ่งอาจไม่เสมอไป (อนุมัติแล้วอาจมีเงื่อนไขอื่น) — ตอบตามสำนวนไทย: **ตอบ ข** ปกติใช้ "จึงจะ" หมายถึง needed condition

### ตัวอย่างที่ 4 (ยาก)
เงื่อนไข 3 ข้อ: (1) ถ้า A แล้ว B (2) ถ้า B แล้ว C (3) ไม่ C — สรุปได้ว่า?
ก. A ข. ไม่ A ค. B ง. ไม่มีข้อใดถูก
**วิเคราะห์**: A→B→C, แต่ ¬C → contrapositive ของ (2): ¬C → ¬B; ของ (1): ¬B → ¬A — ไล่กลับได้ ¬A ✅ **ตอบ ข**

## กับดักที่พบบ่อย

1. สลับปัจจัย-ผลโดยไม่ negate (Q→P) — ไม่สมมูล
2. "ไม่ P → ไม่ Q" (inverse) — ไม่สมมูล
3. "ก็ต่อเมื่อ" มองเป็น "ถ้า" ธรรมดา — ผิด เพราะมันคือ ↔
4. ข้อความ "บางคน..." สรุปเป็น "ทุกคน..." — เกินหลักฐาน
5. เงื่อนไขซ้อน (A→B→C) ลืมไล่ทีละขั้น

<div class="cheat-sheet">

### 📋 สรุปหน้าเดียว

- P → Q: P จริง→Q จริง · Q เท็จ→P เท็จ (contrapositive สมมูล)
- ต้อง…จึง… = Q → P (จำเป็น) · ก็ต่อเมื่อ = P ↔ Q
- ห้ามสลับ Q→P · ห้าม inverse ¬P→¬Q
- "บางคน" ≠ "ทุกคน"
- เงื่อนไขซ้อน: ไล่กลับจากสิ่งที่รู้สุดท้าย
</div>
