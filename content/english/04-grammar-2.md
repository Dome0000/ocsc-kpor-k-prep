# วิชา 2 · ไวยากรณ์ 2 — Conditionals, Passive Voice, Relative Clauses, Modals, Comparison, Gerund/Infinitive, Connectors, Parallel Structure

## เป้าหมายการเรียนรู้และแนวโน้ม

- เลือกโครงสร้างเงื่อนไข (if-clause) ให้ถูกทั้ง 3 แบบ + mixed
- แปลง active ↔ passive และรู้ว่าเมื่อใดประโยคราชการใช้ passive
- เลือก relative pronoun (who/which/that/whose) ถูกต้อง
- ใช้ modal verbs (must/may/might/should/can/could) สื่อความหมายถูก
- เปรียบเทียบชั้นเดียว/ขั้นสูง/as…as
- แยก gerund (V-ing) กับ infinitive (to + V1) ที่ตามหลังคำต่างกัน
- เลือก connectors (however/therefore/moreover/although) ให้สัมพันธ์กับใจความ
- จับ parallel structure (โครงสร้างขนาน) ที่พัง

**แนวโน้ม**: หมวดนี้เป็นจุดที่ข้อสอบ ก.พ. ชอบออกที่สุดในวิชาไวยากรณ์ — โดยเฉพาะ **conditionals, connectors, และ parallel structure** เพราะวัดความเข้าใจเชิงตรรกะ ไม่ใช่แค่จำกฎ

## หลักพื้นฐานจากศูนย์

### 1) Conditionals (ประโยคเงื่อนไข)

| แบบ | รูป | ความหมาย | ตัวอย่าง |
|---|---|---|---|
| Type 0 | If + V1, V1 | ความจริงทั่วไป | If you heat water, it boils. |
| Type 1 | If + V1, will + V1 | เป็นไปได้ในอนาคต | If it rains, we will cancel the trip. |
| Type 2 | If + V2 (were), would + V1 | สมมุติปัจจุบัน/อนาคต (ไม่จริง) | If I were you, I would accept. |
| Type 3 | If + had + V3, would have + V3 | สมมุติอดีตที่ผ่านมา (เสียใจ/ตำหนิ) | If she had studied, she would have passed. |
| Mixed | If + had + V3, would + V1 | อดีตส่งผลถึงปัจจุบัน | If he had saved money, he would be rich now. |

**กฎเหล็ก**: ห้ามใช้ will/would ใน if-clause (If it will rain ✗ → If it rains ✓) · Type 2 ใช้ "were" กับทุกประธานในภาษาทางการ (If I were you / If he were here)

### 2) Passive Voice (กรรมวาจก)

รูป: **be + V3** (+ by …) — ใช้เมื่อ "ผู้กระทำไม่สำคัญ/ไม่รู้/อยากเน้นสิ่งถูกกระทำ" — ภาษาทางราชการ (ระเบียบ/ประกาศ) ใช้ passive บ่อยมาก

- Active: The director **signed** the order. → Passive: The order **was signed** by the director.
- Modal: The form **must be submitted** by Friday. (must + be + V3)
- ตัวอย่าง: The meeting **was postponed** due to bad weather. / All applications **will be reviewed** next week.

### 3) Relative Clauses (อนุประโยคขยายนาม)

| ตัวเชื่อม | ใช้ขยาย | ตัวอย่าง |
|---|---|---|
| who | คน (ประธาน) | The officer **who** handles this case… |
| whom | คน (กรรม) | The man **whom** we met… (มักละได้) |
| which | สิ่งของ/สัตว์ | The report **which** you sent… |
| that | คน/สิ่ง (ไม่มีจุลภาค) | The file **that** is missing… |
| whose | ความเป็นเจ้าของ | The employee **whose** ID was lost… |

**จุดที่ออกสอบ**: มีจุลภาค (non-defining) → ห้ามใช้ that · คน + กรรม → whom/who · เจ้าของ → whose

### 4) Modals (กริยาช่วย)

- **must** = ต้อง (หน้าที่/บังคับ) — Employees must submit timesheets weekly.
- **have to** = ต้อง (เงื่อนไขภายนอก) — You have to wear a uniform.
- **may / might** = อาจจะ (may สุภาพกว่า / 50%, might น้อยกว่า)
- **should** = ควรจะ (คำแนะนำ) — You should check the details.
- **can / could** = สามารถ / สุภาพในการขอ — Could you please sign here?
- **must not** = ห้าม · **don't have to** = ไม่จำเป็นต้อง (คนละความหมาย!)
- **had better** + V1 = ควร (มีคำเตือนแฝง) — You had better hurry.

### 5) Comparison (การเปรียบเทียบ)

- ขั้นกว่า: adj สั้น + **-er** + than (cheaper) · **more / less** + adj ยาว + than (more efficient)
- ขั้นสูงสุด: **the** + adj-est / most + noun (the most effective policy)
- เท่ากัน: **as … as** (as soon as possible · as effective as expected)
- ผิดบ่อย: more better / the most biggest · เทียบ 2 สิ่งใช้ขั้นกว่า (between the two, A is faster)
- **the + ขั้นกว่า …, the + ขั้นกว่า** (The sooner, the better.)

### 6) Gerund (V-ing) vs Infinitive (to + V1)

- **ตามด้วย V-ing เท่านั้น**: enjoy · avoid · finish · suggest · mind · admit · deny · consider · keep · practice · look forward to
- **ตามด้วย to + V1 เท่านั้น**: want · decide · plan · promise · hope · agree · refuse · afford · manage · would like · offer · choose
- **ตามด้วยอะไรก็ได้ (ความหมายต่างกัน)**: stop V-ing = เลิกทำ · stop to V = หยุดเพื่อไปทำอย่างอื่น · remember V-ing = จำได้ว่าเคยทำ · remember to V = อย่าลืมไปทำ · try V-ing = ลองทำดู · try to V = พยายามทำ
- **หลังบุพบทใช้ V-ing**: interested in **learning** · good at **solving** · before **leaving**

### 7) Connectors (คำเชื่อม — วัดความสัมพันธ์ของใจความ)

| ความสัมพันธ์ | คำเชื่อม |
|---|---|
| ขัดแย้ง | however · nevertheless · although · though · despite · in spite of · but · yet |
| เหตุ-ผล | therefore · thus · consequently · because of · due to · so |
| เพิ่มเติม | moreover · furthermore · in addition · besides · also |
| ตัวอย่าง/สรุป | for example · such as · in conclusion · in summary |
| เวลา/เงื่อนไข | meanwhile · afterwards · unless · provided that · as long as |

**จุดออกสอบ**: although + ประโยค แต่ despite/in spite of + นาม · because + ประโยค แต่ because of/due to + นาม · however ใช้ขึ้นประโยคใหม่ ไม่ใช่คำเชื่อมหน้าประโยคเดียวกัน

### 8) Parallel Structure (โครงสร้างขนาน)

คำเชื่อมคู่ **and / or / but / not only…but also / either…or / both…and** ต้องเชื่อมโครงสร้างที่เหมือนกัน:

- ✗ The job requires typing, filing, **and to answer** the phone. → ✓ …typing, filing, **and answering** the phone.
- ✗ She is responsible **for approving and to monitor** budgets. → ✓ …**for approving and monitoring**…

## 4 ตัวอย่าง

### ตัวอย่างที่ 1 (ง่าย — conditional Type 1)
If the budget is approved, the project ______ next month.
- (ก) starts (ข) will start (ค) would start (ง) started

**วิเคราะห์**: If + V1 → result clause ใช้ will + V1 → **(ข) will start**

### ตัวอย่างที่ 2 (กลาง — passive)
All applications ______ by the committee before the interview.
- (ก) will review (ข) reviewed (ค) will be reviewed (ง) are reviewing

**วิเคราะห์**: applications (นาม) + ต้องการ "ถูกพิจารณา" → passive → **(ค) will be reviewed**

### ตัวอย่างที่ 3 (กลาง — connector)
The report was well researched; ______, it lacked clear recommendations.
- (ก) moreover (ข) therefore (ค) however (ง) consequently

**วิเคราะห์**: ใจความขัดแย้ง (ดีแต่ขาดคำแนะนำ) → **(ค) however**

### ตัวอย่างที่ 4 (ยาก — parallel + gerund/infinitive)
The new manager is skilled at negotiating, ______ and resolving conflicts.
- (ก) to motivate (ข) motivating (ค) motivate (ง) motivated

**วิเคราะห์**: โครงสร้างขนานหลัง "at" + gerund: negotiating, …ing, resolving → **(ข) motivating**

## กับดักที่พบบ่อย

1. **will ใน if-clause** — ออกทุกชุด ตัดตัวเลือกที่มี will/would ในส่วน if ทันที
2. **must not vs don't have to** — ต้องห้าม / ไม่จำเป็นต้อง สลับกันพังหมด
3. **although vs despite** — although + ประโยค · despite + นาม/วลีเท่านั้น
4. **passive หลงลืม be** — "The file submitted yesterday" (ขาด was) ในภาษาทางการผิด → "The file was submitted"
5. **parallel structure** — เจอ and/or/but ให้เช็คโครงสร้างสองฝั่งทันที
