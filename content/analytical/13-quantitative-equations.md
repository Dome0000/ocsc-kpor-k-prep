# วิชา 1 · เชิงปริมาณ — สมการและอสมการ

## เป้าหมายการเรียนรู้และแนวโน้ม

- แก้สมการเชิงเส้นตัวแปรเดียว/สองตัวแปร และสมการกำลังสองอย่างง่าย
- แก้ระบบสมการ 2 สมการ 2 ตัวแปร
- แก้อสมการเชิงเส้นและบอกช่วงคำตอบ

**แนวโน้ม**: โจทย์ 1–3 ข้อ/ชุด — เน้นการแก้เร็วและตรวจคำตอบ

## แนวคิดหลักจากศูนย์

**สมการเชิงเส้น**: ทำให้ตัวแปรอยู่ข้างเดียว — จำนวนที่บวกอยู่ ย้ายไปเป็นลบ; คูณอยู่ ย้ายไปหาร

**ระบบสมการ 2×2**: วิธีแทนค่า (substitution) หรือกำจัดตัวแปร (elimination)

**อสมการ**: แก้เหมือนสมการ แต่ <strong>คูณ/หารด้วยค่าลบต้องกลับเครื่องหมาย</strong>

**สมการกำลังสอง**: x² + bx + c = 0 → แยกตัวประกอบ (x+p)(x+q) = 0 โดย p+q = b, p×q = c — รากคือ −p, −q

<div class="formula-box"><div class="fb-title">📌 สูตรที่ต้องจำ</div>

- ย้ายข้าง: a + b = c → a = c − b · a × b = c → a = c/b
- ระบบ 2×2: คูณสมการให้สัมประสิทธิ์เท่ากัน แล้วลบ/บวกเพื่อลดเหลือตัวแปรเดียว
- กำลังสอง: (x + p)(x + q) = 0 · ผลราก = c · ผลรวมราก = −b
- อสมการ: คูณ/หารด้วยลบ → กลับเครื่องหมาย (>, <, ≥, ≤)
</div>

## 4 ตัวอย่าง

### ตัวอย่างที่ 1
2x + 6 = 14 — x = ?
**วิเคราะห์**: 2x = 8 → x = **4**

### ตัวอย่างที่ 2
ระบบ: x + y = 12, x − y = 4 — x = ?
**วิเคราะห์**: บวกสองสมการ: 2x = 16 → x = **8**

### ตัวอย่างที่ 3
อสมการ 3x − 4 ≤ 11 — ช่วงคำตอบ?
**วิเคราะห์**: 3x ≤ 15 → x ≤ **5**

### ตัวอย่างที่ 4 (ยาก)
x² − 7x + 12 = 0 — รากคือ?
**วิเคราะห์**: หาคู่ที่บวกกัน −7 คูณกัน 12 → (−3)+(−4) = −7, (−3)(−4) = 12 → (x−3)(x−4) = 0 → x = **3 หรือ 4**

## กับดักที่พบบ่อย

1. อสมการคูณ/หารด้วยลบแล้วลืมกลับเครื่องหมาย
2. ย้ายข้างลืมเปลี่ยนเครื่องหมาย
3. รากกำลังสองลืม 2 คำตอบ (±)
4. ระบบสมการแทนค่าผิดสมการ

<div class="cheat-sheet">

### 📋 สรุปหน้าเดียว

- สมการ: ตัวแปรข้างเดียว ตัวเลขอีกข้าง · ย้ายข้าง กลับเครื่องหมาย
- ระบบ: กำจัดตัวแปรโดยบวก/ลบ (ทำสัมประสิทธิ์เท่ากันก่อน)
- อสมการ: เหมือนสมการ + กลับเครื่องหมายเมื่อคูณ/หารด้วยลบ
- กำลังสอง: แยกตัวประกอบ · รากคือค่าที่ศูนย์
</div>
