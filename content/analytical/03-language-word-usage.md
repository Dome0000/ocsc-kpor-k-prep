# วิชา 1 · เชิงภาษา — การใช้คำและโครงสร้างประโยค

## เป้าหมายการเรียนรู้และแนวโน้ม

- เลือกใช้คำให้ถูกความหมายและระดับภาษา (ทางการ/กึ่งทางการ/พูด)
- จับผิดโครงสร้างประโยค: การใช้คำฟุ่มเฟือย, ประโยคกำกวม, ความบกพร่องของสมุหนานุกรม ฯลฯ
- เข้าใจความแตกต่างของคำใกล้เคียง เช่น ประมาณ/คาด, หาก/ถ้า, ได้รับ/ได้รับการ

**แนวโน้มที่ออกสอบ**: เติมคำในช่องว่าง, เลือกประโยคที่ถูก/ผิด, ระบุส่วนที่บกพร่องของประโยค — มักเป็นภาษาราชการ

## แนวคิดหลักจากศูนย์

**ระดับภาษาไทย** มี 3 ระดับ: (1) ภาษาพูด/ไม่เป็นทางการ (2) ภาษาเขียนกึ่งทางการ (3) ภาษาทางการราชการ — ข้อสอบ ก.พ. ใช้ภาษาทางการ ดังนั้นคำตอบต้องเป็นคำที่ใช้ในจดหมายราชการ ไม่ใช่คำพูด

**คู่คำที่สอบบ่อย**
| คู่คำ | ความต่าง |
|---|---|
| หาก / ถ้า | "หาก" ทางการกว่า "ถ้า" — ในเอกสารใช้ "หาก" |
| ประมาณ / คาด | "ประมาณ" = ตัวเลขโดยประมาณ, "คาด" = การคาดการณ์ |
| ได้รับ / ได้รับการ | "ได้รับ" + คำนาม (ได้รับเงิน), "ได้รับการ" + กริยา (ได้รับการคัดเลือก) |
| เพื่อ / เพื่อที่จะ | เกือบใช้แทนกันได้ แต่ "เพื่อที่จะ" เน้นเจตนาชัดกว่า |
| กรณี / กรณีย์ | "กรณี" = สถานการณ์, "กรณีย์" ไม่มีในพจนานุกรม |
| อนุญาต / ยินยอม | "อนุญาต" = ให้ทำ (ทางการ), "ยินยอม" = ตกลง |

**ความฟุ่มเฟือย**: "ทำการแก้ไข" → "แก้ไข" ก็พอ · "เรื่องก็คือ" → ตัดทิ้ง

## กล่องหลักการ

<div class="formula-box"><div class="fb-title">📌 วิธีตรวจประโยคราชการ 3 ขั้น</div>

1. **ความหมายตรง** — คำที่ใช้จริงหรือใช้ผิดความหมาย?
2. **โครงสร้าง** — ประธาน-กริยา-กรรม ครบไหม กำกวมไหม
3. **ระดับภาษา** — ทางการพอไหม (หาก/ถ้า, ณ/ที่, ซึ่ง/อัน)
</div>

## 4 ตัวอย่าง

### ตัวอย่างที่ 1
เติมคำ: "หน่วยงาน ___ ดำเนินการตามระเบียบที่กำหนด"
ก. ต้อง ข. อยาก ค. น่าจะ ง. คง
**วิเคราะห์**: เชิงบังคับในเอกสารราชการ → "ต้อง" **ตอบ ก** (อยาก/น่าจะ/คง = ไม่บังคับ)

### ตัวอย่างที่ 2
ประโยคใดถูกโครงสร้าง:
ก. "โครงการนี้ได้รับการอนุมัติจากกรม" ข. "โครงการนี้ได้รับอนุมัติจากกรม" ค. "โครงการนี้อนุมัติจากกรม"
**วิเคราะห์**: "ได้รับการ" + กริยา → "ได้รับการอนุมัติ" ถูกต้อง ✅ **ตอบ ก** (ข ใช้ "ได้รับอนุมัติ" ได้เช่นกันจริง แต่รูปแบบทางการคือ "ได้รับการอนุมัติ" — ระวัง: "ได้รับ + คำนาม" เช่น ได้รับเงิน ก็ถูก; ในข้อสอบ ก. เป็นทางการที่สุด)

> โน้ต: ทั้ง ก และ ข ภาษาไทยยอมรับได้ แต่ข้อสอบมักต้องการรูปทางการ "ได้รับการ…" — เจอข้อสอบจริงให้อ่านตัวเลือกอื่นประกอบ

### ตัวอย่างที่ 3
หาข้อผิด: "นายกรัฐมนตรีเดินทางไปตรวจราชการที่จังหวัดเชียงใหม่เมื่อวานนี้"
ก. คำ "นายกรัฐมนตรี" ข. คำ "เดินทาง" ค. คำ "ตรวจราชการ" ง. ไม่มีข้อผิด
**วิเคราะห์**: ภาษาราชการพูดถึงผู้นำว่า "ฯพณฯ" ปฏิเสธไม่ได้ แต่ในเอกสารทั่วไป "นายกรัฐมนตรีเดินทาง..." เป็นปกติ → ข้อความถูกไวยากรณ์หมด **ตอบ ง**

### ตัวอย่างที่ 4 (ยาก)
เลือกประโยคที่ **กระชับและถูกต้องที่สุด**:
ก. "เพื่อที่จะเป็นการอำนวยความสะดวกให้แก่ประชาชน หน่วยงานจึงได้ทำการขยายเวลาให้บริการออกไป"
ข. "เพื่ออำนวยความสะดวกแก่ประชาชน หน่วยงานจึงขยายเวลาให้บริการ"
ค. "เรื่องก็คือหน่วยงานขยายเวลาเพื่อสะดวก"
ง. "หน่วยงานได้กระทำการขยายเวลาให้บริการเพื่อความสะดวก"
**วิเคราะห์**: ข สั้น ถูกหลัก ตัดคำฟุ่มเฟือย ("เพื่อที่จะเป็นการ"→"เพื่อ", "ได้ทำการ"→"ขยาย") — ก ฟุ่มเฟือย ค ภาษาพูด ง ฟุ่มเฟือยมาก **ตอบ ข**

## กับดักที่พบบ่อย

1. ใช้ภาษาพูดในเอกสารราชการ (อยาก/คง/เรื่องก็คือ/มาก ๆ)
2. "ได้รับการ" ตามด้วยคำนาม (ผิด: "ได้รับการเงิน" → ถูก "ได้รับเงิน")
3. คำคู่ใกล้เคียงสลับกัน (ประมาณ/คาด, หาก/ถ้า ในระดับทางการ)
4. ประโยคกำกวม — "เขาเห็นผู้จัดการกับพนักงานที่ตึกนั้น" (ใครอยู่ที่ตึกนั้น?)
5. ลืมว่าคำตอบเดียวต้อง "ทั้งถูกไวยากรณ์และระดับภาษา"

### 📋 สรุปหน้าเดียว

- ภาษาทางการ: หาก (ไม่ใช่ ถ้า), ณ (ไม่ใช่ ที่), ได้รับการ + กริยา, ได้รับ + คำนาม
- ตัดคำฟุ่มเฟือย: ทำการ, เพื่อที่จะเป็นการ, เรื่องก็คือ
- ประโยคราชการ = ประธาน + กริยา + กรรม ครบ ไม่กำกวม ไม่พูด
- คำคู่สอบบ่อย: ประมาณ/คาด, อนุญาต/ยินยอม, กรณี
