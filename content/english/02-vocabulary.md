# วิชา 2 · คำศัพท์ (Vocabulary)

## เป้าหมายการเรียนรู้และแนวโน้ม

- รู้ความหมายของศัพท์ระดับกลางที่ใช้ใน **สำนักงาน ราชการ ข่าวสาร ธุรกิจ**
- เลือก **synonym (คำที่ความหมายใกล้เคียง)** ได้ในบริบท — รูปแบบที่ออกสอบบ่อยที่สุด
- รู้จัก **collocations** (คู่คำที่ใช้ด้วยกันเป็นธรรมชาติ) และ **phrasal verbs** พื้นฐาน
- เดาความหมายคำศัพท์จากบริบทในประโยค (vocabulary in context)

**แนวโน้ม**: ข้อสอบไม่ค่อยถามคำแปลตรง ๆ แต่ถาม "คำที่ขีดเส้นใต้มีความหมายใกล้เคียงที่สุดกับข้อใด" หรือ "คำใดใช้เติมในช่องว่างได้" — ดังนั้นต้องรู้ทั้งความหมายและการใช้คู่กับคำอื่น

## หลักพื้นฐานจากศูนย์

### แหล่งศัพท์ที่ควรท่อง (จัดลำดับความสำคัญ)

1. **ศัพท์สำนักงาน/ราชการ** — meeting, report, budget, approve, submit, deadline, document, memo, agenda, policy, procedure, regulation, responsibility, authority, effective (มีผลบังคับใช้), comply (ปฏิบัติตาม), implement (นำไปปฏิบัติ)
2. **คำกริยาออกสอบบ่อย** — achieve, require, involve, provide, consider, improve, reduce, increase, affect (กระทบ), effect (ผล/ทำให้เกิด), accept, except (ยกเว้น), advice (คำแนะนำ น.), advise (แนะนำ ก.)
3. **คู่ synonym ที่ออกซ้ำ ๆ**

- important ≈ significant / crucial / vital / essential
- big ≈ large / huge / enormous / vast
- small ≈ tiny / minor / slight / little
- difficult ≈ hard / tough / challenging / complicated
- easy ≈ simple / straightforward / effortless
- quick ≈ fast / rapid / swift / prompt
- help ≈ assist / aid / support / facilitate
- show ≈ display / demonstrate / illustrate / reveal
- use ≈ utilize / employ / apply / make use of
- need ≈ require / demand / want / be in need of
- try ≈ attempt / endeavor / strive
- happen ≈ occur / take place / arise / emerge
- begin ≈ start / commence / initiate
- end ≈ finish / conclude / terminate / cease
- buy ≈ purchase / acquire / obtain
- get ≈ obtain / receive / acquire / gain
- give ≈ provide / offer / grant / supply
- ask ≈ request / inquire / seek
- tell ≈ inform / notify / advise / notify
- fix ≈ repair / mend / resolve / address

### Collocations (คู่คำที่ใช้ด้วยกัน)

| กริยา | คู่กับ | ตัวอย่าง |
|---|---|---|
| make | a decision / a mistake / an effort / progress | The committee made a decision yesterday. |
| do | homework / business / research / damage | We do business with overseas partners. |
| take | action / measures / responsibility / part | The agency took immediate action. |
| have | a meeting / an impact / experience | The new policy had a big impact. |
| provide | services / information / support | The office provides services to the public. |
| conduct | a meeting / research / an inspection | The audit was conducted last week. |
| meet | a deadline / a requirement / expectations | All staff must meet the deadline. |

### Phrasal verbs ที่พบบ่อย

- **carry out** = ดำเนินการ (carry out a plan / inspection)
- **deal with** = จัดการกับ (deal with a complaint)
- **look into** = ตรวจสอบ (look into the matter)
- **put off** = เลื่อน (put off the meeting)
- **come up with** = คิดหา (come up with an idea)
- **point out** = ชี้ให้เห็น (point out the error)
- **figure out** = หาทางออก/เข้าใจ (figure out the problem)
- **look forward to** = รอคอย (look forward to hearing from you) — **to + คำนาม/กริยา-ing**
- **carry on** = ดำเนินต่อ (carry on working)
- **turn down** = ปฏิเสธ (turn down the offer)

### คำศัพท์ที่หน้าคล้ายกันแต่ความหมายต่าง (confusing words)

| คู่คำ | ความหมาย |
|---|---|
| affect (ก.) / effect (น.) | affect = กระทบ · effect = ผล / ทำให้เกิด |
| advice (น.) / advise (ก.) | advice = คำแนะนำ · advise = แนะนำ |
| accept / except | accept = ยอมรับ · except = ยกเว้น |
| principal / principle | principal = หลัก/ครูใหญ่ · principle = หลักการ |
| stationery / stationary | stationery = เครื่องเขียน · stationary = หยุดนิ่ง |
| complement / compliment | complement = ส่วนเติมเต็ม · compliment = คำชม |
| ensure / insure / assure | ensure = ทำให้มั่นใจ · insure = ประกัน · assure = รับรองให้ไว้ใจ |

## 4 ตัวอย่าง

### ตัวอย่างที่ 1 (ง่าย — synonym)
The manager's **crucial** role is to approve budgets. The word "crucial" is closest in meaning to:
- (ก) minor (ข) important (ค) optional (ง) frequent

**วิเคราะห์**: crucial = สำคัญมาก ≈ important → **(ข)**

### ตัวอย่างที่ 2 (กลาง — collocation)
Please ______ the deadline, or the report will be late.
- (ก) make (ข) take (ค) meet (ง) do

**วิเคราะห์**: meet the deadline = ส่งทันกำหนด (collocation มาตรฐาน) → **(ค)**

### ตัวอย่างที่ 3 (กลาง — in context)
"The new regulation will **take effect** next Monday." means it will ______.
- (ก) be cancelled (ข) begin to apply (ค) be discussed (ง) fail

**วิเคราะห์**: take effect = มีผลบังคับใช้ ≈ begin to apply → **(ข)**

### ตัวอย่างที่ 4 (ยาก — confusing words)
The policy will ______ all government agencies.
- (ก) effect (ข) affect (ค) effort (ง) afford

**วิเคราะห์**: ต้องการคำกริยา "กระทบ" → **affect** → **(ข)** (effect เป็นคำนาม "ผล" หรือกริยา "ทำให้เกิด" แต่ใช้ไม่ตรงบริบทนี้)

## กับดักที่พบบ่อย

1. เลือกคำที่ "แปลคล้าย" แต่ collocation ผิด — เช่น "make homework" (ผิด) ต้องเป็น "do homework"
2. สลับ affect / effect, advice / advise, accept / except — ออกซ้ำแทบทุกชุด
3. เลือก synonym ที่ความหมาย "เกือบใช่" แต่แรงกว่า/เบากว่าเกินไป — ดูระดับความแรงของคำ (important < crucial < vital)
4. เดาจากหน้าตาคำ (false friends) — เช่น "eventually" ≠ อย่างไรก็ตาม (ที่ถูกคือ "ในที่สุด"; "however" = อย่างไรก็ตาม)
5. ลืมว่า look forward to + -ing ไม่ใช่ to + V1

<div class="cheat-sheet">

### 📋 สรุปหน้าเดียว

- ศัพท์ราชการต้องจำ: approve · comply · implement · regulation · procedure · authority · effective · responsibility
- synonym ชุดออกบ่อย: important≈significant · need≈require · show≈demonstrate · help≈assist · happen≈occur
- collocation ทอง: make a decision · meet a deadline · take action · conduct a meeting · provide services · carry out a plan
- phrasal verb ทอง: carry out · deal with · put off · look into · point out · look forward to + -ing
- confusing words: affect/effect · advice/advise · accept/except · principal/principle
- ท่องเป็น "ประโยคตัวอย่าง" ไม่ใช่ท่องเดี่ยว ๆ — จะจำ collocation ได้เอง
</div>
